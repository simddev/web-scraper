# Web Crawler

A command-line web crawler written in TypeScript that generates an internal links report for any website. Give it a URL and it will crawl every page it can find, then report which pages link to which — useful for auditing internal link structure.

## Requirements

- Node.js 22.15.0 (via [nvm](https://github.com/nvm-sh/nvm))

## Setup

```bash
nvm use
npm install
```

## Usage

```bash
npm start
```

## Testing

```bash
npm test
```
